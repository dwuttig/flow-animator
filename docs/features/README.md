# Feature specs

One Markdown file per new feature or idea, named `<short-name>.md`. Copy [TEMPLATE.md](TEMPLATE.md).
Every spec names its bounded context and slice (see [../architecture.md](../architecture.md)).
A spec says **what** and **why**. The **how** goes in [`../plans/`](../plans/) under the same name.

Status values: `proposed`, `accepted`, `implemented`, `rejected`.
